# Claude Pre-Authorization Analysis System

AI-powered healthcare decision support system for UAE insurance pre-authorization analysis using specialized Claude Code agents.

## Quick Start

```bash
# Install dependencies (from project root)
uv add claude-code-sdk loguru

# Run analysis (from project root)
chmod +x claude_preauth_system/preauth_analyze.sh
./claude_preauth_system/preauth_analyze.sh <json_request> <patient_folder>
```

## Example Usage

```bash
# Analyze a patient's current request (from project root)
./claude_preauth_system/preauth_analyze.sh \
  data/processed_data/11f5688b-6c4a-4c41-baad-71e6a4b82d91/abudhabi_11f5688b-6c4a-4c41-baad-71e6a4b82d91_20200214_req01_shafafiya.json \
  data/processed_data/11f5688b-6c4a-4c41-baad-71e6a4b82d91/

# List available patient folders (UUID-based)
ls data/processed_data/

# List available requests for a patient
ls data/processed_data/11f5688b-6c4a-4c41-baad-71e6a4b82d91/*.json

# View results
ls analysis_results/analysis_*/
```

## System Components

- **orchestrator.py** - Python orchestrator coordinating 5 medical agents
- **preauth_analyze.sh** - User-friendly bash wrapper with JSON validation
- **Medical Agents** - Self-contained in `agents/` directory with specialized expertise
- **Results** - Saved to `analysis_results/analysis_TIMESTAMP/`

## Data Format

- **Input**: JSON files in FHIR Bundle format (generated by `pipelines/data_pipeline.py`)
- **Processing**: Multi-agent analysis with clinical reasoning
- **Output**: Comprehensive analysis reports with approval recommendations

## Output Files

Each analysis generates:
- `comprehensive_final_report.md` - Executive summary and recommendations
- `{agent-name}_analysis.md` - Individual specialist reports (5 files)
- `{agent-name}_debug.log` - Detailed processing logs (5 files)
- `analysis_metadata.json` - Processing statistics and timing
